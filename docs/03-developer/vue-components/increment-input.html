Increment input ​

This component is used to select numbers with the option to increase or decrease them.

How to use ​

vue
<increment xname="name" xvalue="110"
 xmax="1000" xmin="0"
></increment>
  • xname: The name used in the form.
  • xvalue: The default number.
  • xmin: The minimum value.
  • xmax: The maximum value.
