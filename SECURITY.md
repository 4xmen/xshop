Important: Read Before Reporting Security Issues

Please review the following before submitting a security vulnerability report.

Features intentionally available to authorized Developer or Administrator users, such as uploading files or entering custom JavaScript, HTML, Google Analytics snippets, or other scripts, are not security vulnerabilities by themselves.

A valid report must demonstrate a concrete security impact, such as unauthorized access, privilege escalation, bypassing access controls, or code execution by an unauthorized user.

Reports that merely describe intended functionality without demonstrating a security impact may be closed as Not Applicable.

Please include reproducible steps, the required permissions, and a clear proof of the security impact in every report.

Thank you for helping us keep this project secure.
